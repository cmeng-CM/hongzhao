# Jinja2 模板继承

Jinja2 的模板继承由两个语法构成：

- `{% extends %}`：子模板在文件顶部声明继承的父模板，例如 `{% extends "base.html" %}`；声明后子模板只负责填充块。
- `{% block %}`：父模板中用 `{% block 名称 %}...{% endblock %}` 定义可覆盖块；子模板中用同名块替换父模板的默认内容。

要点：`extends` 必须是子模板中的顶层标签；块名在模板树中用于定位覆盖点；父模板的块内容可作为回退默认值。
